核心问题：如何用数学语言描述随机现象、概率分布，以及不同概率分布之间的关系？这是后续 VAE、Diffusion、RL 和 LLM 后训练的共同数学基础。

概念复用地图：Lab 03 的 Monte Carlo 估计会在强化学习阶段重新出现（策略梯度）；Lab 04 的 KL 散度会在 VAE、PPO、DPO 中反复出现；Lab 05 的「MLE = 最小化交叉熵 = 最小化 KL」是一切神经网络训练的理论内核。

## 实验列表

| Lab | 主题 | 知识块 |
|---|---|---|
| 01 | 一维与二维概率分布 | 密度与概率、协方差矩阵几何、直方图估计、线性变换采样 |
| 02 | 联合分布与条件分布 | 边缘、Schur 补、混合反例、窄带估计 |
| 03 | Monte Carlo 估计 | 无偏性、标准误差、$1/\sqrt n$ 收敛、稀有事件 |
| 04 | 概率分布度量 | 熵、交叉熵、KL、Brier Score |
| 05 | 最大似然估计 | 闭式解、估计偏差、MLE = 交叉熵 = KL |

## 概念接口

**前置依赖**：无（全书起点）。

**后续复用**：Monte Carlo 估计 → 策略梯度（Lab 28/30/45）；KL 散度 → VAE 正则（Lab 15）、PPO 约束（Lab 30）、DPO（Lab 39）；条件分布 → 扩散条件链（Lab 19）、MDP 转移核（Lab 23）、SFT（Lab 37）。

## 工程要求

MLX 数组运算与随机采样、Matplotlib 可视化（实现约定见前言）。

## 阶段验收

能独立解释和计算：联合/边缘/条件分布的换算（可手工推导二维高斯条件分布）；从协方差矩阵预测等密度椭圆的形状与朝向；Monte Carlo 标准误差与 $1/\sqrt n$ 收敛；$H(P,Q) = H(P) + D_{\mathrm{KL}}(P\|Q)$ 与 NLL 均值 = 交叉熵。五个实验的自测全部变绿。
