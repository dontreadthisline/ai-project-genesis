这是一本以实验为骨架的教材。数学推导服务于实验，知识点服务于实验，最终目标只有一个：读完本书并完成配套实验之后，能够独立实现并训练一个 Agentic RL 系统。

## 全书主线

$$
\text{Probability}
\rightarrow
\text{Deep Learning}
\rightarrow
\text{Generative Models}
\rightarrow
\text{RL}
\rightarrow
\text{LLM}
\rightarrow
\text{Agentic RL}
$$

从概率与信息论出发，经过深度学习、生成模型、强化学习、语言模型，最终抵达 Agentic RL。三条实验脉络贯穿其间：MNIST（深度学习与生成模型）、Gymnasium（强化学习）、TinyStories（语言模型），最后在可验证的工具环境中汇合。

## 本书结构

| 部分 | 主题 | 核心问题 |
|---|---|---|
| 一 | 概率建模与信息论 | 如何用数学语言描述随机现象与分布之间的关系？ |
| 二 | 深度学习与序列建模 | 神经网络如何通过梯度优化学习复杂函数？ |
| 三 | 生成模型 | 如何让网络学习数据分布并生成新样本？ |
| 四 | 强化学习 | 通过与环境交互获得反馈时如何优化策略？ |
| 五 | LLM 预训练与后训练 | 深度学习与 RL 机制如何应用于自回归语言模型？ |
| 六 | Agentic RL | 语言模型如何通过多步环境交互完成多步任务？ |
| 附录 | 符号表、概念依赖表 | — |

每一章围绕一个实验展开，固定结构：**理论问题**（本章研究什么）→ **数学基础**（完整推导，可白板复现）→ **实现任务**（代码接口与自测）→ **对照实验**（自变量、控制变量、因变量）→ **预期图表与观测指标** → **结果分析** → **验收清单**。

同一数学概念会在多个部分反复出现：Monte Carlo 估计先在第一部分出现，第四部分以策略梯度的身份回归；KL 散度从信息论出发，途经 VAE、PPO，最终落在 DPO 与 GRPO；「最小化交叉熵 = 最大似然 = 最小化 KL」这一等式，则是从第二部分起每一次训练的理论内核。这些跨部分的联系在各章末尾的「概念接口」中标注，附录 B 给出全景汇总。

## 如何使用本书

讲义与实验代码是同一课程的两条轨道，配套使用：

- **讲义（本书）**负责「为什么」：推导、实验设计、结果如何对照理论预期、验收标准。
- **实验代码（`code/` 目录，每个实验一个独立项目）**负责「怎么做」：待实现的函数骨架加自测断言。正确的工作流是先让自测通过，再做对照实验，最后对照验收清单自查。

```bash
cd code/lab01-pdf-and-covariance
uv sync                 # 准备环境
uv run run_lab01.py     # 自测 -> 对照实验 -> 图表与指标
```

学习节奏上，本书采用阶段验收制：每个部分有明确的验收标准，达到标准再进入下一部分。以每周 10 小时计，全程约 5-7 个月；时间不是硬性要求，验收标准才是。

## 实现约定

全书实验统一用 MLX 实现（数组计算用 `mlx.core`，第二部分起网络用 `mlx.nn`）。NumPy 只在明确标注的边界场景出现（数据文件解析、个别 MLX 缺失的原语），Matplotlib 对 mx.array 直接可用。

三条贯穿全书的约定：

1. **随机数**：每个实验脚本开头 `mx.random.seed(0)`，函数签名不携带随机状态，结果可复现。
2. **惰性求值**：MLX 的计算默认延迟执行，打印、比较、画图前需要 `mx.eval()` 强制求值。
3. **数值精度**：默认 float32；数值梯度检验与闭式解对照使用 float64（需 CPU 设备）。

MLX 当前版本的具体局限与标准应对，见第一部分导览的「MLX 与 NumPy 的边界」一节。
